# Auralis Nexus · BETA

Bases de datos locales con explorador paginado, filtros, constructor de consultas, parámetros, biblioteca de consultas, mapa de relaciones, análisis y comprobaciones de integridad. Parte del entorno común [Auralis](https://github.com/OscarD0823/auralis).

[Usar aplicación](https://oscard0823.github.io/auralis-nexus/) · [Descargas](https://github.com/OscarD0823/auralis-nexus/releases)

Código propio en src/. Una misma implementación genera la aplicación independiente y la global. Datos locales, sin subir documentos. SQLite conserva la base completa y las consultas guardadas; CSV, TSV, JSON y XLSX exportan hasta 100.000 filas sin truncar silenciosamente. ACCDB/MDB y VBA completo siguen pendientes.
